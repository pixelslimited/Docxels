# Docxels feature tracker

Product: **Docxels** by Pixels Limited. Code base: native **Kotlin + Jetpack Compose + Material 3, Android only** (package `com.docscan.app`). The master specification assumed Flutter and iOS; the project was already native Android, so features are added to it rather than rebuilt (decision by the owner: "you are only adding these features").

Statuses: `NOT STARTED` · `IN PROGRESS` · `IMPLEMENTED — NOT VERIFIED` · `TESTED` · `BLOCKED`.
`TESTED` means automated tests passed in CI. Nothing is marked tested on a real phone yet: there is no device or instrumented-test setup, so every imaging and UI feature is at best `IMPLEMENTED — NOT VERIFIED`.

## Audit (spec part 25)

**Exists.** Camera capture with auto-capture and modes; edge detection; perspective warp; text-line dewarp; deskew; colour-safe flatten; photocopy B&W; hand / object / staple / fold removal; book-spread split; page arrange; OCR (ML Kit, bundled); table detection; exports (PDF, images, TXT, Word via OCR, Excel / Word / PDF / image for tables); Room database; private file storage; new home screen; release pipeline with APK on GitHub Releases.
**Added this round.** Word-processor file engine (document model, .docx writer and reader, unit-tested, opened in python-docx and LibreOffice); security layer (encrypted pages, app lock, secure screen, no network permission, import limits); settings screen; public site and store listing; this tracker.
**Build / test tools available.** GitHub Actions: Kotlin compile, JVM unit tests, R8 release build, APK size and permission report. Not available: Android emulator or device, instrumented tests, Flutter, Dart, iOS.
**Biggest risks.** (1) Imaging quality is proven only on synthetic photos. (2) R8-shrunk release has not run on a phone. (3) Rich-text editor on Android `EditText` needs careful span handling and a pagination layer (not started). (4) Word fidelity for files saved by Word itself is only tested against a hand-made imitation. (5) Keystore encryption has JVM tests for the format but not a device run.
**Next three tasks.** Scan-to-Word (editable document from a scan, with tables) with tables and PDF export from the editor → signatures and PDF import / fill.
